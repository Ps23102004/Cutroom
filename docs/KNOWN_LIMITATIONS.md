# Known limitations

Not a complete Cutroom studio. Frontend architecture and preliminary tooling/assets exist; no Rust/Tauri native core has been implemented. Core production persistence, ingestion, composition rendering, durable jobs/recovery, transcription/search, AI proposal enforcement, immutable revisions, review service/exact approvals, delivery, archives, support actions/tickets/operator service, packaging and release certification remain unimplemented or unintegrated.

The GLM5.2 backend and GLM5.3 review runs were actually attempted and rejected by provider quota 429/1310. Required replacement permission is pending. Gemini frontend and Luna tooling work proceeded independently; this is not claimed as GLM participation.

Browser/UI tests cannot establish native project durability or media accuracy. Synthetic FFmpeg fixture checks test the installed tool, not a Cutroom export engine. Local model smoke is a handful of synthetic prompts, not held-out recording evaluation or product certification.

Google image tool returned an artifact but does not expose its underlying model identity. OpenAI output metadata identifies gpt-image2.0. Both initial study silhouettes were rejected as geometry masters; OpenAI colors/material remain a useful reference. The actual GLB is procedural from the approved brief. ComfyUI's configured weight library is on the absent Project Dev volume; no image-to-mesh conversion has occurred.

No public review/support service, unsigned native package, signing/notarization, hosted deployment or showcase demo of the complete workflow exists. Publication remains a separate authorization boundary.
