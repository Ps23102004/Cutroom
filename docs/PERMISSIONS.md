# Permission scope

Authorized: new Cutroom source/docs/fixtures; reviewed local builds/tests; loopback development services; existing coding subscriptions/routes; bounded image studies after internal asset approval.

Separate approval required: new charges, large model/tool downloads, public deployment/push/showcase submission, private-media upload, destructive user-data operations, global configuration changes, persistent background services, signing credentials or human-only OS/account gates. No blanket permission bypass flags. Do not execute arbitrary model-proposed shell commands. Do not dump credentials or configuration secrets.

Development harness credentials never enter product runtime or archives. Local production, hosted review and hosted inference have separate backend-enforced consent scopes.
