## 2. Systematic Defect Resolutions

### 2.1 Appearance & Accessibility (Defect 1)
- **Problem:** Route-local fake `reducedMotion` and `highContrast` switches were disconnected from CSS and unpersisted, falsely claiming to toggle vector fallbacks or border contrast.
- **Resolution:** Removed the fake interactive switches and route-local state. Provided truthful, read-only information:
  - Reduced-motion follows system and browser preferences (`prefers-reduced-motion`), directly observed by `Cutline`. In-app manual override is unavailable and not saved.
  - Enhanced contrast custom override is marked unavailable, with border styling following display/browser defaults until native theme engine integration.

### 2.2 Storage & Filesystem Roots (Defect 2)
- **Problem:** Hardcoded "124 GiB Free • Local SSD / APFS" and editable `/workspace/projects` and `/workspace/cache` input fields invented machine state.
- **Resolution:** Removed fabricated capacity and filesystem claims. Removed fake editable inputs and invented default paths. Default project directory, scratch store path, and data volume capacity are explicitly reported as unavailable until reported by the desktop engine.

### 2.3 Models & Media Engine (Defect 3)
- **Problem:** Hardcoded assertions of Apple Silicon Neural Engine acceleration, mlx-whisper, Apple Silicon VideoToolbox, detected FFmpeg 9.0.1 in PATH, and EBU R128 loudness pipeline contradicted the disconnected native runtime.
- **Resolution:** Replaced all hardcoded capabilities with truthful runtime-unavailable readings:
  - Local Speech ASR Worker: Marked target `mlx-whisper / Whisper CoreML` with status "Runtime unavailable (desktop engine not connected)".
  - Local Assembly & Proposal Planner: Marked "Runtime unavailable (desktop engine not connected)".
  - Hardware Encoder: Reported as "Unavailable (requires desktop engine)".
  - FFmpeg Binary Version: Reported as "Unavailable — not detected (requires desktop engine)".
  - Audio Processing Pipeline: Reported as "Unavailable (requires desktop engine)".

### 2.4 Privacy & Local Bounds (Defect 4)
- **Problem:** Promotional "Local-First Guarantee" copy made unverified promises; disconnected telemetry toggle switch gave the illusion of persistent consent.
- **Resolution:** Replaced promotional text with accurate current preview behavior: project edits, timelines, and state are contained within the browser session without remote cloud sync; native filesystem persistence and export pipelines require the desktop engine. Removed disconnected telemetry switch and explicitly stated that diagnostics sending is unavailable.

### 2.5 Diagnostics (Defect 5)
- **Problem:** "Generate Sanitized Bundle (.json)" button had no click handler, presenting a dead control.
- **Resolution:** Disabled the button (`disabled={true}`) and added adjacent explanation: "Desktop engine unavailable — diagnostics bundle cannot be generated in browser preview." No fabricated sanitized report is output.

### 2.6 TopBar Affordances & Status Wording (Defect 6)
- **Problem:** Status badge read "Browser Preview (No Tauri)" rather than plain engine unavailable phrasing. "Load Sample Fixture" button was publicly visible in production mode despite AppContext gating fixture mode to `import.meta.env.DEV`.
- **Resolution:** 
  - Replaced badge text with "Browser Preview (Engine unavailable)".
  - Gated the entire fixture affordance in `TopBar.tsx` behind `{import.meta.env.DEV && (...)}`, aligning presentation with context-level authorization.
